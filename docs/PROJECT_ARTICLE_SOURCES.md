## 内容选择

- 优先阅读与五个项目直接相关的 Markdown 需求与操作说明。Word/PDF 同名副本不重复当作独立证据。
- 不纳入其他业务合同、题库明细、客户订单、个人联系方式及无关业务资料。
- 文章来源集中列在文末；不将本地私有路径做成公网链接。
- 保留旧卡片作为按主题探索的材料，文章承担连贯叙事；旧卡片标注的原型边界不自动升级成生产事实。

## 实现与链接

- `#article` 打开完整文章，`#article-section-1` 至 `#article-section-5` 为正文目录。
- 原较大章节编号保留为相关章节内的兼容锚点。历史章节编排已经重写，不承诺旧编号对应同一标题。
- 原生 HTML 包含文章、目录与入口，禁用 JavaScript 仍可阅读。
- 共用脚本负责文章、卡片、文字目录切换；未改动文件夹展开算法或原型实现。
