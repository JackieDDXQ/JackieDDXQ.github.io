# 首页首屏：工作与思考关系地图

用户指定参考 `lab/spatial-system.html` 的网络样式，允许重新斟酌内容。本轮以整幅关系地图替换首屏的左右分栏与叠放卡片，其他首页集合和权益页不变。

## 构图与内容

- 以 Jackie Hou 和产品经理身份为中心，主题节点散布于周围；保留灰白底、浅色圆角节点、细连线和克制的阴影。
- 使用业务建模、规则与取舍、用户体验、协作机制、从方案到实践、开放思考六个主题。它们是阅读入口，不是经过评估的能力等级或独立成果主张。
- 每个主题展开一个具体问题与两份已有材料，覆盖权益、多租户商城、命题协作和出行权益。没有照搬参考中的研究、建筑背景等内容集合，也没有引入指标。
- 权益项目入口仍在地图右下方，连接下方现有项目收藏。
- 主题间的边代表本轮编辑组织的阅读联系，不表示业务执行方向或已验证的因果关系。

## 实现与访问

`assets/styles/home-atlas.css` 和 `assets/scripts/home-atlas.js` 仅在首页加载；实验页面和权益项目页不改动。静态链接有可访问的真实目标；脚本增强后点击主题展开中央内容，修饰键点击仍能访问原始链接。Escape/返回全景恢复焦点。

连线按节点 DOM 边界计算，并通过 SVG 遮罩避让中央文字。只在尺寸变化与交互时刷新，没有持续动画循环。CSS 遵守 reduced-motion。手机保持纵向网络构图和原生页面滚动，不截获滚轮或触摸。
