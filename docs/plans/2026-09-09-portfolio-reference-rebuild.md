# 首页与权益页设计语言的全站延伸

用户反馈上一版内页与现有首页、权益页不一致，要求重新制作。

## 实施

- 项目索引直接复用首页 collection 组件：主项目文件夹、材料预览、其他项目文件夹及问题视角切换。
- 七个传统内页移除 site.css、redesign.css、旧内联样式和旧动画脚本。collection.css 负责公共组件，重写后的 portfolio-theme.css 独立负责内页排版。
- 项目详情使用紧凑导读、浅色材料页、分组判断与原型入口。关于、经历、联系采用首页的字号、阅读宽度与留白节奏。
- 保留原有事实内容、原型 URL 和首页、权益页、出行页；本次不改独立业务原型。

## 检查

- 七页在 390px 视口下无横向溢出，未发现控制台错误。
- 桌面检查项目索引、项目详情、关于及联系页视觉。
- 本地链接目标存在；已清除七页对旧主题的依赖。
