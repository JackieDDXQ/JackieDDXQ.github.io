# 首页内容层级合并设计

## 目标

- 将独立的项目索引并入代表项目，形成“主要项目 + 更多项目”的单一作品模块。
- 降低 Working Statement 的纵向体量，移除信息密度偏低的 SYSTEM 示意块。
- 保留首页到完整项目页的清晰入口，并维持桌面与移动端可用性。

## 方案

### Working Statement

保留核心主张、解释文字与 Focus / Method / Practice 三项信息。删去大幅 STRUCTURE / SYSTEM 图形，将标题断句收敛为三行，并缩小模块上下留白，使它成为 Hero 与项目内容之间的短编辑序言。

### Selected Work

以运营商权益全链路管理平台作为主要项目，保留现有项目叙述和架构图。主要项目下方直接加入“更多项目”清单，展示命题智能协同平台与和包 APP 出行权益生态。移除独立项目索引的标题、浅色背景和大预览框，避免同一批作品被拆成两个视觉模块。

“查看全部 5 个项目”放在更多项目标题右侧，跳转 `projects.html`。移动端改为上下排列，项目类型与年份按现有响应式规则隐藏。

## 验证

- 桌面端检查两部分是否形成连续叙事，并确认文字对比度。
- 390px 移动端检查标题断行、项目行和完整项目入口。
- 检查键盘焦点、横向溢出、页面链接、静态构建与浏览器错误。
