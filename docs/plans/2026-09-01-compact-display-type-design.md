# 紧凑展示字号设计

## 目标

保留首页开屏标题的视觉冲击力，同时缩小首页其余模块、顶层内页和案例页的大字号，减少标题对画面的压迫感。

## 字号策略

- 首页 Hero 标题保持现状。
- 页面级标题和案例封面标题缩小约 17%—18%。
- 模块标题缩小约 14%—20%。
- 项目列表、方法卡片等中型标题缩小约 12%—16%。
- 正文、辅助标签、导航和原型应用界面不调整，避免影响阅读性与功能密度。

通过 `redesign.css` 中的共享字号变量统一控制顶层页面和案例页；首页因 `motion.css` 位于样式链末端，在该文件中同步调整非 Hero 标题。所有相关页面更新样式版本号，确保部署后不命中旧缓存。

## 验证

- 首页开屏字号保持不变。
- 首页 Statement、主要项目、经历与联系标题明显缩小。
- 项目、关于、经历、联系页面的页面标题及模块标题层级清晰。
- 案例页封面、章节标题和大数字结果不过度占据视口。
- 检查 1440px、768px 和 390px 宽度，不产生截断或横向溢出。
